## [Takeout in full](#Takeout-in-full)

<details open><summary><p lang="en"><b><u>Click/tap here to expand/collapse this section</u></b></p></summary>

> **Status:** `✅️ Success`

Data can be taken out in full, the user is given the option to export their entire inbox in either MBOX (MailBox) or individual EML files. The user can choose where to put these files. Since ProtonMail is encrypted, data takeout will take a lot longer than other email services without encryption, which ensures data safety. For an inbox of about 6,093 emails, it took over 2 hours to export. I tested, it takes the same amount of time to export as MBOX and individual EML files.

</details>

## [Standard format](#Standard-format)

<details open><summary><p lang="en"><b><u>Click/tap here to expand/collapse this section</u></b></p></summary>

> **Status:** `✅️ Success`

The user is given the option to export their entire inbox in either MBOX (MailBox) or individual EML files. The user can choose where to put these files. Both EML and MBOX are very common and standard formats used for email.

Standard formats include, but are not limited to:

```plain-text
JSON, MP4, MP3, ZIP, TXT, JS, CSS, HTM, HTML, ODT, PDF, XML, SVG, OGG, OGA, PNG, JPG, GIF, JP2, JPE, ISO, YAML, EPUB, OGV, WEBM, MKV, ODS, ODP, ODB, SQL
```

Standard formats must have high levels of recognition, and cannot be a special format created by the owner of the site, unless said format is an international recognized ISO standard.

</details>
